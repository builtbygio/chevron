# Historical Atom RFCs

These files are **archived Atom-era RFCs** (wording, links, and `atom/atom` assumptions unchanged). They are not Chevron product specs.

Dead Flight Manual or atom.io API links inside individual RFCs are left as historical citations. Current contribution and package policy live in [CONTRIBUTING.md](../../CONTRIBUTING.md) and [contributing-to-packages.md](../orientation/contributing-to-packages.md).
