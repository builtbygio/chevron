# About package

View useful information about your Chevron installation.

This is a package for [Chevron](https://github.com/builtbygio/chevron), a hackable text editor for the 21st Century.

## Usage

This package provides a cross-platform "About Chevron" view that displays information about your Chevron installation, which currently includes the current version, the license, and the Terms of Use.

## Contributing
Always feel free to help out!  Whether it's filing bugs and feature requests
or working on some of the open issues, Chevron's [contributing guide](https://github.com/builtbygio/chevron/blob/master/CONTRIBUTING.md)
will help get you started while the [guide for contributing to packages](https://github.com/builtbygio/chevron/blob/master/CONTRIBUTING.md)
has some extra information.
