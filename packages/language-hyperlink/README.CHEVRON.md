# language-hyperlink (Chevron)

Injection grammar (`text.hyperlink`) for URLs in text, strings, comments,
and GFM. Ships as JSON (`grammars/hyperlink.json`). 13c: no CSON in
`grammars/` / `settings/` / `snippets/`. Spec fixtures may still be CSON.

Owned so the pin is not an archived `atom/*` remote.
Chevron loads this via `packageDependencies`.
