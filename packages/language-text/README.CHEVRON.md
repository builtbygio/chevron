# language-text (Chevron)

Plain-text highlighter (`text.plain`) and shared snippets. Ships as JSON
(`grammars/plain text.json`, `snippets/language-text.json`). 13c: no CSON
in `grammars/` / `settings/` / `snippets/`.

Owned so the pin is not an archived `atom/*` remote.
Chevron loads this via `packageDependencies`.
