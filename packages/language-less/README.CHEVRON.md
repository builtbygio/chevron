# language-less (Chevron)

Less highlighter. Tree-sitter is the default (`tree-sitter-less`).
TextMate fallback is `grammars/less.json`. Settings ship as JSON
(`settings/language-less.json`). 13c: no CSON in `grammars/` /
`settings/` / `snippets/`. `spec/` may still have Coffee.

Owned so the pin is not an archived `atom/*` remote.
Chevron loads this via `packageDependencies`.
