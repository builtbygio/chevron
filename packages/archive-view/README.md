# Archive view package

Maintained for [Chevron](https://github.com/builtbygio/chevron). Lists archives through [builtbygio/ls-archive](https://github.com/builtbygio/ls-archive) (tar 7), not npm `ls-archive@1.3.4`.

Adds support for browsing archive files with the following extensions:

* `.egg`
* `.epub`
* `.jar`
* `.love`
* `.nupkg`
* `.tar`
* `.tar.gz`
* `.tgz`
* `.war`
* `.whl`
* `.xpi`
* `.zip`

Select a file to extract it to a temp file and open it in a new editor.
